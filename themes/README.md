# Themes

Every `.ask` file below this folder is installed into Live's theme chooser by
`install.sh`. Keep each theme's licence and notice in the same subfolder as
the files it covers: the installer copies only the `.ask` files.

They go into
`<install folder>/push3_opt/push3/products/live/Live/AppLive/Resources/Themes/`
by file name, replacing a file of the same name. Ableton's own themes are not
touched.

`catppuccin/` holds the two themes from the Wires distribution. They are
LGPL-2.1 and are not covered by this repository's GPL-3.0 licence; see the
`NOTICE` and `LICENSE` in that folder.
